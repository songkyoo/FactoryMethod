# Factory Method

타입에 `AutoFactory`를 적용하여 생성자에 대응하는 정적 팩토리 메서드를 자동으로 생성하는 C# 소스 제네레이터입니다.

## 빌드하기

다음과 같은 순서로 명령을 수행하여 NuGet 패키지를 생성할 수 있습니다.

```shell
dotnet build -c Release
dotnet pack ./FactoryMethod/FactoryMethod.csproj -c Release
```

`./FactoryMethod/bin/Release/` 폴더에 `nupkg` 확장자를 가지는 패키지가 생성됩니다.

## 사용법

### 타입에 `AutoFactory` 어트리뷰트 선언하기

타입을 `partial`로 선언하고 `AutoFactory` 어트리뷰트를 적용하면 매개 변수가 없는 생성자에는 `New`, 매개 변수가 있는 생성자에는 `Of` 이름을 가진 팩토리 메서드를 생성합니다. 기본 생성 대상은 접근 제한자가 `public`, `internal`인 생성자입니다.

```csharp
using Macaron.FactoryMethod;

[AutoFactory]
public partial class Foo
{
    public Foo() { }

    public Foo(int bar) { }

    public Foo(int bar, string baz) { }

    internal Foo(int bar, int baz) { }

    protected Foo(int bar, string baz, int qux) { }
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    public static Foo New() => new();

    public static Foo Of(int bar) => new(bar);

    public static Foo Of(int bar, string baz) => new(bar, baz);

    internal static Foo Of(int bar, int baz) => new(bar, baz);
}
```

기존 멤버와 생성될 팩토리 메서드의 충돌은 검사하지 않습니다. 충돌이 있다면 생성자에 `FactoryMethodName`을 적용하여 이름을 변경하거나 `IgnoreAutoFactory`를 적용하여 생성 대상에서 제외해야 합니다.

대상이 되는 생성자의 매개변수가 파스칼 케이스인 경우 카멜 케이스로 변경됩니다.

```csharp
using Macaron.FactoryMethod;

[AutoFactory]
public partial record Foo(int Bar, string Baz);
```

위와 같은 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial record Foo
{
    public static Foo Of(int bar, string baz) => new(bar, baz);
}
```

### 특정 생성자를 대상에서 제외하기

`AutoFactory`가 적용된 타입에서 `IgnoreAutoFactory` 어트리뷰트를 생성자에 적용하면 팩토리 메서드 생성 대상에서 제외됩니다. `IgnoreAutoFactory`는 다른 생성자 어트리뷰트보다 우선합니다.

```csharp
using Macaron.FactoryMethod;

[AutoFactory]
public partial class Foo
{
    public Foo(int bar) { }

    [IgnoreAutoFactory]
    public Foo(int bar, string baz) { }
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    public static Foo Of(int bar) => new(bar);
}
```

### `private` 생성자 포함하기

`AutoFactory`의 `IncludePrivateConstructors`를 `true`로 설정하면 `private` 생성자도 팩토리 메서드 생성 대상에 포함됩니다. `private` 생성자에 대응하는 팩토리 메서드의 접근 제한자는 `public`입니다.

```csharp
using Macaron.FactoryMethod;

[AutoFactory(IncludePrivateConstructors = true)]
public partial class Foo
{
    public Foo(int bar) { }

    [FactoryMethodName("FromValues")]
    private Foo(int bar, string baz) { }

    [IgnoreAutoFactory]
    private Foo(int bar, string baz, bool qux) { }

    protected Foo(string value) { }
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    public static Foo Of(int bar) => new(bar);

    public static Foo FromValues(int bar, string baz) => new(bar, baz);
}
```

`IncludePrivateConstructors`는 접근 제한자가 정확히 `private`인 생성자만 추가로 포함합니다. `protected`, `protected internal`, `private protected` 생성자는 이 옵션을 사용해도 생성 대상에 포함되지 않습니다.

### 팩토리 메서드 이름 변경하기

생성자에 `FactoryMethodName`을 적용하면 해당 생성자의 팩토리 메서드 이름을 변경합니다. 비어 있는 이름은 생성자의 매개 변수 유무에 따라 기본 이름인 `New` 또는 `Of`를 사용합니다.

```csharp
using Macaron.FactoryMethod;

[AutoFactory]
public partial class Foo
{
    [FactoryMethodName("CreateEmpty")]
    public Foo() { }

    public Foo(int bar) { }

    [FactoryMethodName("FromValues")]
    public Foo(int bar, string baz) { }
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    public static Foo CreateEmpty() => new();

    public static Foo Of(int bar) => new(bar);

    public static Foo FromValues(int bar, string baz) => new(bar, baz);
}
```

팩토리 메서드 생성을 활성화하는 어트리뷰트는 타입에 적용하는 `AutoFactory`뿐입니다. 타입에 `AutoFactory`가 없으면 생성자에 적용된 `FactoryMethodName`과 `IgnoreAutoFactory`는 무시됩니다. 또한 `FactoryMethodName`은 생성자를 대상에 추가하지 않으므로, `private` 생성자를 포함하려면 `IncludePrivateConstructors`를 함께 설정해야 합니다.
